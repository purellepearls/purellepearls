PURELLE PEARLS — WEBSITE COMPANY PROFILE
========================================

ISI WEBSITE
- index.html : halaman Home
- about.html : halaman About Us dan formulir kontak demo
- style.css  : semua desain, tipografi, layout, dan responsivitas
- script.js  : menu mobile, tahun otomatis, dan interaksi form
- assets/    : folder untuk aset lokal tambahan

CARA MEMBUKA DI VS CODE
1. Ekstrak ZIP ke folder komputer.
2. Buka Visual Studio Code.
3. Pilih File > Open Folder, lalu pilih folder Purelle_Pearls_Website.
4. Buka index.html.
5. Untuk tampilan yang nyaman, pasang ekstensi "Live Server" di VS Code.
6. Klik kanan index.html > Open with Live Server.
7. Navigasi Home dan About Us sudah saling terhubung.

CATATAN
- Website menggunakan HTML, CSS, dan JavaScript terpisah.
- Layout responsif untuk desktop, tablet, dan HP.
- Foto produk dan Google Fonts menggunakan layanan online sehingga membutuhkan internet.
- Form kontak hanya demo front-end; pesan belum dikirim ke email/server.
- Alamat email pada halaman About adalah contoh dan dapat diganti sesuai alamat perusahaan.
- Purelle Pearls adalah konsep brand untuk proyek website.
